Setup

What each part needs to work with this hub. Addresses and tokens come from the hub's config, {{.Config}}, which the portal never changes: to change a token, edit it there, restart the hub, and change it wherever it's used.

  • Speech node
  • Mac
  • Phone
  • Apple push

Add a speech node

The GPU computer that hears and speaks calls: Linux with an NVIDIA GPU.

1

On that machine, with a copy of the repository, install it (2.7 GB to download) and build it:

speech/install.sh
speech/build.sh
2

Set the hub's address and the speech token in ~/ringback-speech/speech.toml:

{{- if .SpeechSet}} 
hub = "ws://{{.Listen}}/speech"
token = "••••••••••••••••"
{{- else}}

The hub's config has no speech token yet. Set speech under [tokens] to a long random string, such as openssl rand -hex 32 prints, and restart the hub.

{{- end}}
3

Start it. It links to the hub and shows on the status page's map.

. ~/ringback-speech/env.sh && ~/ringback-speech/bin/ringback-speech serve
Run it as a service, from boot 
mkdir -p ~/.config/systemd/user
cp speech/ringback-speech.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now ringback-speech
loginctl enable-linger                       # so it runs from boot, not only while you're logged in
journalctl --user -u ringback-speech -f      # its log

Add a Mac

A Mac whose Claude Code sessions call you.

1

On the Mac, from the repository, build the agent and copy its config:

mkdir -p ~/.local/bin ~/.config/ringback
(cd agent && go build -o ~/.local/bin/ringback-agent .)
cp agent/agent.example.toml ~/.config/ringback/agent.toml
2

Set the hub's address and the agent token in ~/.config/ringback/agent.toml:

{{- if .AgentSet}} 
hub = "{{.Listen}}"
token = "••••••••••••••••"
{{- else}}

The hub's config has no agent token yet. Set agent under [tokens] to a long random string, such as openssl rand -hex 32 prints, and restart the hub.

{{- end}}
3

Start it. It links to the hub and shows on the status page's map, with its sessions.

~/.local/bin/ringback-agent serve
Start it at login, with launchd 
cat > ~/Library/LaunchAgents/ringback.agent.plist <<EOF
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key>
  <string>ringback.agent</string>
  <key>ProgramArguments</key>
  <array>
    <string>$HOME/.local/bin/ringback-agent</string>
    <string>serve</string>
  </array>
  <key>EnvironmentVariables</key>
  <dict>
    <key>PATH</key>
    <string>$(dirname "$(which claude)"):/usr/bin:/bin:/usr/sbin:/sbin</string>
  </dict>
  <key>RunAtLoad</key>
  <true/>
  <key>KeepAlive</key>
  <true/>
  <key>ThrottleInterval</key>
  <integer>30</integer>
  <key>StandardOutPath</key>
  <string>$HOME/Library/Logs/ringback-agent.log</string>
  <key>StandardErrorPath</key>
  <string>$HOME/Library/Logs/ringback-agent.log</string>
</dict>
</plist>
EOF
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/ringback.agent.plist
4

Load the ringback mod in Claude Code, for every session, in ~/.claude/settings.json; then /ringback in a session turns calling on:

{ "env": { "CLAUDE_CODE_PLUGIN_DIRS": "/path/to/ringback/mod" } }

Apple push

{{if and .PushSet (not .PushProblem)}}Set up in the hub's config.{{else if .PushSet}}Set up, but with a problem.{{else}}Not set up yet.{{end}} The hub rings the phone through Apple's push service, with a key from your Apple Developer account.

{{- with .PushProblem}}

Calls can't ring: {{.}}.

{{- end}}
1

At developer.apple.com, under Certificates, Identifiers & Profiles, Keys, make a key with Apple Push Notifications, and download its .p8 file to the hub's machine.

2

Add it to {{.Config}}, with your team ID and the app's bundle ID, then restart the hub:

[apns]
team_id = "ABCDE12345"
bundle_id = "com.example.ringback"

[apns.sandbox]
key_id = "XYZ9876543"
key_file = "~/.config/ringback/AuthKey_XYZ9876543.p8"

Builds installed from Xcode get their pushes from Apple's sandbox, so that's the key you need. TestFlight and App Store builds need [apns.production].

The whole setup, the hub's too, is in the repository's docs/setup.md.

{{end}}{{end}}
